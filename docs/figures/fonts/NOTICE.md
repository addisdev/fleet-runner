# Fonts

The faces the generated assets are set in, self-hosted so that
`npm run assets` renders the same image on every machine. Both are under the
SIL Open Font License 1.1; the licence text for each is beside it.

| File | Face | Copyright | Licence |
|---|---|---|---|
| `BricolageGrotesque.woff2` | Bricolage Grotesque, variable, weights 600–700, Latin subset | 2022 The Bricolage Grotesque Project Authors (<https://github.com/ateliertriay/bricolage>) | [`OFL-Bricolage.txt`](OFL-Bricolage.txt) |
| `IBMPlexSans.woff2` | IBM Plex Sans, variable, weights 400–500, Latin subset | 2017 IBM Corp., Reserved Font Name "Plex" | [`OFL-IBMPlex.txt`](OFL-IBMPlex.txt) |
| `IBMPlexMono-400.woff2`, `IBMPlexMono-500.woff2` | IBM Plex Mono, Latin subset | 2017 IBM Corp., Reserved Font Name "Plex" | [`OFL-IBMPlex.txt`](OFL-IBMPlex.txt) |

The subsets are the Latin `woff2` files Google Fonts serves for these
families. The OFL permits redistribution of the fonts, modified or not, so long
as they are not sold on their own and the Reserved Font Names are not used for
a modified version; nothing here modifies them.
